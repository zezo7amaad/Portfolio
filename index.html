Security Write-ups

Severity: Informational
Password Reset Token Invalidation Flaw
Insufficient Security Configurability > Weak Password Reset Implementation

The application fails to invalidate existing password reset tokens when a user updates their password through account settings. Consequently, a reset link requested prior to the password change remains active, allowing an unauthorized party to override the new password.

Reproduction & Impact:

  • Business Risk: Users who suspect their account is compromised and attempt to secure it by changing their password remain vulnerable, as pre-existing reset links act as a persistent backdoor.
  • Steps: Request a reset link ➔ Log in and update password via Settings ➔ Use the old reset link ➔ Observe that the old token overrides the new password update.
  • Remediation: Implement a last_password_change timestamp or token_version counter to instantly invalidate tokens issued prior to a password modification.
